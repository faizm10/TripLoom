# API references

External API integrations used by TripLoom.

## Google Maps

- [Google Maps JavaScript API](https://developers.google.com/maps/documentation/javascript) – map embeds, place search, and directions.
- [Google Directions API](https://developers.google.com/maps/documentation/directions) – transit routing between locations.

## OpenAI

- GPT-4.1 for the AI trip-planning assistant and tool-calling workflows.
